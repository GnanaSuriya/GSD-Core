# Project Context: Creator Fan Website

## Core Idea
Create a polished, production-ready fan/community website centered around a real-world YouTube/social-media creator. It will allow visitors to learn about the creator, explore their content, watch featured videos, see achievements, and connect through social media. The application will feel like a premium, modern product rather than a basic portfolio.

## Target Audience
The creator's fans, followers, community members, and new visitors discovering the creator for the first time.

## Technology Stack
- **Frontend Framework**: React
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Language**: JavaScript
- **Architecture**: Component-based
- **Deployment**: Vercel
- **Data**: Static/local data (no unnecessary backend services)

## Design Principles
- **Premium Aesthetics**: Modern, creator-focused design, strong typography, good spacing, and visual hierarchy.
- **Interactivity**: Subtle animations, hover effects, and polished transitions.
- **Responsiveness**: Flawless experience across desktop, tablet, and mobile.
- **Maintainability**: Clean, scalable code architecture avoiding over-engineering.
- **Production-Ready**: High performance, accessibility, secure secrets handling.
